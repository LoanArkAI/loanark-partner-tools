# Loan Ark Partner Tools

Claude skills from **Loan Ark Inc.** for our real estate agent partners.

Install once, and they stay up to date as we improve them.

> **Status: setting up.** No skills are published here yet. This repository is live so partners can add it ahead of the first release.

---

## What this is

A *plugin marketplace* — a catalog Claude can install skills from. A **skill** teaches Claude how to do a specific job the way we'd do it: run a report, draft something in a particular format, work through a checklist. Once installed, Claude uses the skill on its own whenever it fits what you're working on.

## What you need

- **Claude Cowork**, on your own computer
- A **paid Claude plan** — plugins aren't available on the free tier

## How to install

1. Open **Customize** in the Claude sidebar, then **Plugins**
2. Click **Add marketplace**
3. Enter: `LoanArkAI/loanark-partner-tools`
4. Click **Browse plugins**, pick the one you want, and click **Install**

No GitHub account needed.

## Staying up to date

We publish improvements to these skills over time. Claude checks this catalog for new versions — if you ever want to pull the latest immediately, open **Customize → Plugins**, find this marketplace, and click **Update**.
