# Milestones: what each one means to the client

The sequence a buyer's file follows, in order, with what the client should hear and do at each step. Use the "client hears" column as the substance of the message and write it in the agent's voice. "Client does" becomes the ask, or "nothing right now". Listing-side clients only get the rows marked **L**.

| Milestone | Client hears | Client does |
|---|---|---|
| Application received | The loan is officially started with [LO name]. | Watch for the disclosure package by email. |
| Initial disclosures sent | The first set of loan paperwork is out; it explains the loan on a standard form. | Sign it today; the appraisal waits on it. |
| Initial disclosures signed | Paperwork is signed; the lender can order the appraisal. | Nothing. |
| Rate locked (expires [date]) (buyer side only) | The rate is set through [date]; the team works to close before then. | Keep finances exactly as they are. |
| Appraisal ordered **L** | An independent appraiser will visit the home. | Nothing; the seller's side handles access. |
| Inspection scheduled **L** | The inspection is on [date]; it covers condition, separate from the appraisal. | Attend if possible; questions go to the agent. |
| Appraisal received | The appraisal is back and the LO has it. | If anything needs discussing, [LO name] will call today. |
| HOA docs ordered / received | The association's documents are in motion; they can take a while. | Read them when they arrive; ask the agent about anything odd. |
| Insurance (proof) received | Homeowners insurance is lined up and the lender has proof. | Nothing (or: send the policy to [LO name] if not yet received). |
| Title / escrow opened **L** | Title and escrow are working the file. | Watch for escrow's forms and wire instructions (verify by phone before wiring). |
| Submitted to underwriting | The full file is with the underwriter. | Respond same-day to any request from [LO name]. |
| Conditional approval | Approved, with a short list of remaining items. | If an item is yours, [LO name] will tell you exactly what. |
| Conditions submitted | Everything requested has been sent back in. | Nothing. |
| Clear to close **L** | The loan is fully approved. | Watch for the Closing Disclosure. |
| Closing Disclosure sent | The final numbers are out; the three-business-day clock starts once you receive and acknowledge it. | Acknowledge receipt promptly; read it; ask about anything unfamiliar. |
| Closing Disclosure received (3-day clock) | Signing can happen on or after [date]. | Plan the signing appointment. |
| Closing docs to escrow **L** | The loan documents are at escrow / title. | Bring ID to signing. |
| Signing scheduled **L** | Signing is [date, time, place]. | Show up with ID; the funds to close are wired per escrow's verified instructions. |
| Signed **L** | Documents are signed and on their way back to the lender. | Nothing. |
| Funded **L** | The lender has sent the money. | Keys at recording in California; in Colorado and Texas usually at funding. Confirm with the closer. |
| Recorded **L** | The sale is official. | Congratulations. |

Contract dates sit next to loan dates: acceptance, inspection contingency, appraisal contingency, loan contingency, close of escrow. When a loan milestone is expected after a contingency date, the update says so plainly and tells the client the agent is on it; it does not speculate about who is at fault.

## Waiting-on categories (what the agent may say)

Owner categories: Borrower · Buyer's agent · Listing agent · Escrow/Title · HOA · Appraiser/AMC · Insurance · Loan Ark (processing) · Underwriting.

The agent may name the category and the owner ("one item from the HOA, ordered on the 3rd") and never the item's contents when it is a loan condition. The client-facing shape is: what is outstanding, who has it, since when, and what happens when it lands.

## Pipeline stages before a contract (for the weekly summary)

Referred → Contacted → Application started → Application complete → Pre-approved (expires [date]) → Under contract → Funded. For pre-approved clients not yet in contract, the weekly note reminds the agent of the letter's expiry so the buyer stays ready to write.

## Language that stays out

"Came in short", "the underwriter flagged", "their credit", "the ratio", "the lock is going to blow", "we might lose this", "the investor", "conditions: [list]". Replace each with the relevant "client hears" line above or with "[LO name] will call you today."
